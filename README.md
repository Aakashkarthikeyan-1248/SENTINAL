# 🛡️ SENTINAL: AI-Assisted CCTV Incident Intelligence System

**SENTINAL** is an MVP intelligence system for CCTV and surveillance feeds. It detects candidate events (such as unattended luggage/items), captures cropped visual evidence, synthesizes neutral incident summaries, and empowers security operators to triage alerts in real-time.

---

## ⚡ Features
- **Object Detection & Persistence Tracking**: Uses YOLOv8 + ByteTrack to detect and track individuals and luggage/items.
- **Temporal Event Rules**: Evaluates spatial separation and stationary dwell time to identify candidate unattended items.
- **Strict Guardrails & Summaries**: Factual, objective event summaries via Gemini API (with offline deterministic fallback). Intent, guilt, or suspicion are never inferred.
- **Human-in-the-Loop Review Dashboard**: Interactive Streamlit interface to inspect video, verify evidence snapshots, and triage alerts (*Acknowledge*, *Dismiss*, *Escalate*).
- **Dual-Storage Backend**: Default zero-setup local **SQLite** database with seamless one-config switch to **Supabase (Cloud PostgreSQL)**.
- **Git & GitHub Ready**: Pre-configured `.gitignore`, clean directory architecture, and sample generation tools.

## 🚀 Quickstart Guide

### 1. Clone & Set Up Environment
```bash
git clone https://github.com/your-username/sentinal.git
cd sentinal
pip install -r requirements.txt
```

### 2. Configure Environment (`.env`)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Set your credentials:
```ini
# Optional Gemini API key (defaults to deterministic template if not set)
GEMINI_API_KEY=your_gemini_key

# Supabase (Optional: leave empty to use local SQLite sentinal.db)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-key
```

### 3. (Optional) Initialize Supabase
If using Supabase, open your Supabase project's **SQL Editor** and execute [`supabase_schema.sql`](supabase_schema.sql) to create the `incidents` table and policies.

### 4. Launch the Streamlit Dashboard
```bash
streamlit run app.py
```
Open [http://localhost:8501](http://localhost:8501) in your browser.

## 🛡️ Safety & Responsible AI
- All detections are treated as **candidate alerts** requiring human verification.
- Summaries generated by the LLM adhere to strict ethical constraints: never infer intent or guilt, never classify individuals subjectively, and present only measurable physical observations (dwell time, distance, object class).
